# Regression & Classification

This repository is a personal sandbox for learning and implementing basic machine learning models from scratch. 

## 🧠 What's Inside
* **Linear Regression**: Notebooks breaking down cost functions, gradient descent, and a basic restaurant revenue prediction project.
* **Logistic Regression**: Implementation of classification models, including regularization to prevent overfitting.
* **Testing & Tools**: Simple scripts (`public_tests.py` and `utils.py`) to verify calculations and handle data loading.

## 🛠️ Tech Stack
Python, NumPy, Pandas, Matplotlib.
